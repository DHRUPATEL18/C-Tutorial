# C Programming Tutorials – Beginner to Intermediate

This repository contains **C programming tutorial programs** covering core to intermediate-level concepts. Each `.c` file focuses on a specific topic with simple examples and practice-based logic.

The goal of this repository is to help students understand **C fundamentals, memory concepts, and problem-solving using C**.

> ⚠️ **Note:** This is a proprietary tutorial repository intended for learning or authorized use only.

---

## 📌 Requirements

To run these programs, you need:

- GCC compiler (MinGW / GCC / Turbo C)
- VS Code or any C-supported IDE
- Basic command-line knowledge

## ▶️ How to Run the Programs

1. Open terminal in the project folder
2. Compile the program:

```bash
gcc filename.c -o output
```

3. Run the program:

```bash
./output
```

(Windows users may use `output.exe`)
